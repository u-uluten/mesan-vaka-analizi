# MESAN — İşletme Vaka Analizi

Başkent Üniversitesi · İŞLE 499

Utku ULUTEN ve Efe BOZKURT tarafından hazırlanan akademik sunum.

Ana sunum 14 soruyu kapsar. Çözüm eki yalnızca ilgili düğmeyle açılır ve EK 01–03 olarak numaralanır.

Kurumsal fotoğraflar ve film MESAN’ın resmî kaynaklarından; akademik analiz ve öneriler bağımsız öğrenci çalışmasıdır. Bu çalışma MESAN’ın resmî sitesi değildir.
